## Project Objective

The objective of this project is to develop a solution based on the provided design. The source data was extracted from a MySQL database and delivered as CSV files.

To improve the efficiency and usability of our data engineering pipelines, these CSV files must be converted into JSON format. JSON provides better structure, flexibility, and compatibility for downstream applications compared to CSV.

The scope of this project is therefore focused on converting the CSV files into JSON files.
